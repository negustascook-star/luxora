LUXORA — ATSILIEPIMAI IŠ DISCORD (REPUTACIJA)
=============================================
Skiltis "Atsiliepimai" puslapyje kas 30 s skaito +rep žinutes iš
Discord kanalo. Naršyklė pati Discord API kviesti negali (CORS
blokada), todėl užklausa eina per nemokamą tarpininką Cloudflare
Worker. Boto tokenas įvedamas ADMIN PANELĖS Discord skiltyje ir
saugomas tik toje naršyklėje (localStorage) — NIEKADA nedėk boto
tokeno į GitHub failus.

1) BOTAS SERVEYJE
   - Discord Developer Portal -> tavo aplikacija -> Bot -> tokenas.
   - OAuth2 -> URL Generator: scopes [bot], permissions [View Channel,
     Read Message History] -> atidaryk sugeneruotą linką ir pakviesk
     botą į serverį (guild id: 1458179076190769287).
   - Kanale (channel id: 1458541073164013741) botas turi matyti kanalą.

2) WORKER SUKŪRIMAS (nemokama, be Secrets)
   - Užsiregistruok https://dash.cloudflare.com (Free planas tinka).
   - Kairėje: Workers & Pages -> Create -> Create Worker -> Deploy.
   - Edit code: ištrink viską, įklijuok failą reputation-worker.js
     iš šito repo -> Save and deploy.
   - Jokio tokeno į Cloudflare dėti NEREIKIA (B režimas) — nebent
     nori, tada Settings -> Variables -> Secret DISCORD_BOT_TOKEN.
   - Nukopijuok Worker URL, pvz: https://luxora-rep.xxx.workers.dev

3) ADMIN PANELĖ (Discord skiltis)
   - Worker URL: įklijuok Worker URL iš 2) žingsnio.
   - Bot tokenas: įklijuok boto tokeną (saugomas tik šioje naršyklėje).
   - Kanalo ID: 1458541073164013741 (jau įrašytas default).
   - Spausk "Išsaugoti" — puslapis iškart patikrins kanalą.
   - "Tikrinti dabar" — patikrina iš karto, nelaukiant 30 s.
   - Statusas rodo: paskutinį tikrinimą, +rep skaičių ir klaidą jei yra.
   - "Ištrinti tokeną" — pašalina tokeną iš naršyklės.

4) KAIP TIKRINTI AR VEIKIA
   - Atidaryk Worker URL naršyklėje BE tokeno — turi grąžinti klaidą
     apie trūkstamą tokeną (vadinasi Worker gyvas).
   - Parduotuvės skiltis "Atsiliepimai" po ~30 s turi rodyti skaičių
     ir karuselę. Be nustatymų ten rodys "—".
   - Jei klaida "Discord atmetė tokeną": patikrink ar botas serveryje
     ir ar mato kanalą (1 žingsnis).

SVARBU: boto tokeną laikyk tik admin naršyklėje ir (pasirinktinai)
Cloudflare Secrets. Jei tokenas buvo kur nors įklijuotas viešai
(chat, git) — Developer Portale spausk Reset Token.

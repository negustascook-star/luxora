ant Cloudflare (jau turi paskyrą), be jokio PC/serverio. Failas
verify-worker.js. B (index.js + Node) — jei kada turėsi VPS/PC 24/7.

A) WORKER VARIANTAS (nemokama, 24/7, ~10 min darbo)
   Workeris kas 2 min pats patikrina narių sąrašą per Discord REST
   (gateway nereikia, jokių privileged intents nereikia).
   a) Cloudflare -> Workers & Pages -> Create application ->
      Start with Hello World -> vardas pvz. luxora-verify -> Deploy.
   b) Edit code -> ištrink viską -> įklijuok verify-worker.js
      iš šito repo -> Save and deploy. Nukopijuok URL, pvz:
      https://luxora-verify.negustascook.workers.dev
   c) To workerio Settings -> Variables:
      Secrets: DISCORD_BOT_TOKEN (= boto tokenas),
               CLIENT_SECRET (= iš portalo OAuth2).
      Text: GUILD_ID=1458179076190769287,
            VERIFY_ROLE_ID=1458539876226961479,
            CLIENT_ID=1550135782570856558,
            BASE_URL=https://luxora-verify.negustascook.workers.dev
      (savo URL, be "/" gale).
   d) Workers -> KV (kairėje) -> Create namespace, pvz. luxora-verify.
      Tada workerio Settings -> Bindings -> Add binding ->
      KV Namespace, kintamasis: STORE, namespace: ką tik sukurtas.
   e) Workerio Triggers -> Cron -> Add Cron Trigger: kas 2 minutes.
   f) Discord portalas OAuth2 -> Redirects -> pridėk:
      https://luxora-verify.negustascook.workers.dev/callback
   g) Pakviesk botą su admin linku (2 žingsnis žemiau) + boto rolė
      AUKŠČIAU už verify rolę (3 žingsnis).
   h) Palauk 2 min (pirmas cron tik išsaugo sąrašą, nieko nedaro),
      tada testuok su antru accountu (6 žingsnis).
      Tokenai saugomi KV (raktažodis "tokens") — iš KV niekur
      nekelk ir nedalink.

B) NODE VARIANTAS (index.js) — tik jei turi 24/7 mašiną.

1) DISCORD PORTALAS (https://discord.com/developers/applications)
   - Tavo aplikacija (client id jau kode: 1550135782570856558).
   - Bot -> Privileged Gateway Intents: įjunk "SERVER MEMBERS INTENT".
     (Be jo botas NEMATYS, kad kažkas prisijungė.)
   - Bot -> Token: jei reikia naujo — Reset Token.
   - OAuth2 -> Redirects -> Add: <TAVO_HOST_URL>/callback
     (pvz. https://luxora-verify.xxx.railway.app/callback).
     Turi 100% sutapti su .env BASE_URL + "/callback".
   - OAuth2 -> ten pat pasiimk Client Secret į .env.

2) BOTO PAKVIETIMAS SU VISOM TEISĖM (Administrator)
   Atidaryk šitą linką naršyklėje ir pakviesk botą į serverį
   1458179076190769287:
   https://discord.com/oauth2/authorize?client_id=1550135782570856558&permissions=8&scope=bot%20applications.commands
   (permissions=8 = Administrator — visos teisės, įskaitant rolių
   valdymą ir žmonių priėmimą į serverius.)

3) ROLIŲ TVARKA (būtina, kitaip gausi 403 klaidą)
   Server Settings -> Roles: nutempk BOTO rolę AUKŠČIAU už rolę
   1458539876226961479. Botas negali liesti aukštesnių rolių už save.

4) .ENV
   Nukopijuok verify-bot/.env.example į verify-bot/.env ir užpildyk:
   DISCORD_BOT_TOKEN, CLIENT_SECRET, BASE_URL (be "/" gale).
   .env failo NIEKADA nekelk į GitHub.

5) PALEIDIMAS (reikia 24/7, rinkis vieną)
   a) Savo PC (veiks kol įjungtas): verify-bot aplanke
      "npm install", tada "npm start".
   b) Railway.app (paprasčiausias nemokamas hostingas): naujas
      projektas iš šito GitHub repo, root directory: verify-bot,
      Variables: tie patys kaip .env. Railway duos HOST_URL.
   c) Senasis Oracle VPS (kai atgis): nukopijuok verify-bot,
      "npm install", paleisk su pm2 arba systemd.
   Po paleidimo patikrink: atidaryk <HOST_URL>/ — turi rodyti
   "Luxora verify bot veikia."

6) TESTAS
   - Pakviesk antrą (testinį) Discord accountą į serverį.
   - Rolė turi nusinuimti, į PM turi ateiti žinutė su mygtuku.
   - Spaudi mygtuką -> autorizuojiesi -> rolė grįžta + PM "Patvirtinta!".
   - Jei PM neateina: žmogus užsidaręs DM iš serverio narių
     (Privacy Settings) — tada mygtuko jis negaus, teks įjungti.

Jei kas neveikia, žiūrėk boto logus (console): ten parašyta
tiksli priežastis (blogas tokenas, 403 rolės, uždaryti DM ir t.t.).

7) AUTORIZAVUSIŲ TOKENAI (tokens.json)
   Kiekvieno patvirtinto žmogaus OAuth raktai automatiškai išsaugomi
   į verify-bot/tokens.json (access + refresh, su auto atnaujinimu).
   Kam: pakartotinis priėmimas į serverį be naujos autorizacijos.
   - Failas su paslaptimis: NIEKADA nekelk į GitHub (jau .gitignore),
     nedalink, laikyk tik serveryje.
   - Jei nutekėtų: ištrink failą + Discord portale Reset Token,
     žmonės autorizuosis iš naujo.
   - Vartotojai apie saugojimą informuojami PM žinutėje ir
     patvirtinimo puslapyje.
